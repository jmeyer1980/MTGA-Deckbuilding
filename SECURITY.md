# Security Policy

This is a small local-tooling repo (deck construction scripts run against a
personal Arena collection export) with no network-facing service and no
supported release versions to patch.

## Reporting a vulnerability

If you find a security issue in the scripts (e.g. unsafe file handling, code
execution from untrusted input), please open a GitHub issue or contact the
repository owner directly rather than filing a public exploit. There is no
bug bounty; this is a hobby project.
